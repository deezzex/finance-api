# Finance API

Capstone project for the [Node.js learning plan](../learning-plan.md). Built incrementally, one topic at a time — see [`finance-api-plan.md`](../finance-api-plan.md) at the repo root for the full day-by-day mapping.

Started: Week 2, Day 2.

## Current state

Plain Node.js scripts, no framework yet. Account data lives in `data/accounts.json`. Express, Prisma/Postgres, auth, TypeScript, tests, Redis, and Docker all get layered in over the coming weeks per the plan.
